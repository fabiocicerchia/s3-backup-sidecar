🗄️ s3-backup-sidecar

A restic backup sidecar with cron built in and 100% env-driven config.

Mount your data volume, set four env vars, get scheduled, encrypted, deduplicated, retention-managed backups to S3 — or anything restic and rclone speak. Everyone reinvents this container; this one is tested with a real backup → restore → content-verify round-trip against MinIO.

Run
docker run -d \
  -e RESTIC_REPOSITORY=s3:s3.amazonaws.com/my-bucket/my-app \
  -e RESTIC_PASSWORD=hunter2 \
  -e BACKUP_SCHEDULE="0 3 * * *" \
  -v /srv/data:/data:ro \
  fabiocicerchia/s3-backup-sidecar

one-shot: args: ["once"] · disaster recovery: args: ["restore"] · Helm chart included
